# WERT Hausverwaltung — Complete Project

This is the full app. It has two parts that run separately:

    hausverwaltung/
      ├── frontend/   → React website (deploy to Vercel as a static site)
      └── backend/    → Express + MongoDB API (deploy to Vercel-as-a-function OR Render)

The frontend talks to the backend over HTTP. MongoDB connects to the **backend**.

## What was fixed in this version
- Backend: serverless-safe MongoDB connection (cached), fail-fast timeout, CORS
  trailing-slash bug, `trust proxy`, protected admin-seed route, and it now exports
  for Vercel serverless instead of only `app.listen()`. Added `api/index.js` + `vercel.json`.
- Frontend: added the MISSING Tailwind / PostCSS / Autoprefixer dependencies and
  `postcss.config.js`. Without these a fresh install (like Vercel's) ships an unstyled site.

## NOT included (you regenerate / create these)
- `node_modules` in both folders  → run `npm install` (standard; never shipped in a zip)
- `backend/.env`                   → create it from `backend/.env.example` (it held a secret)
- build output                     → regenerated by `npm run build`

## Run locally (to confirm everything works)
1. Backend:  `cd backend` → copy `.env.example` to `.env` and fill values → `npm install` → `npm run dev`
   You should see `✅ MongoDB connected`. API at http://localhost:5000
2. Frontend: `cd frontend` → `npm install` → `npm start`  → opens http://localhost:3000
   (In dev the frontend proxies /api to the backend automatically — no env var needed.)

## Deploy
Full step-by-step is in **backend/DEPLOY.md**. Short version:
1. MongoDB Atlas → Network Access → allow 0.0.0.0/0. Reset the leaked password.
2. Deploy backend (Vercel project OR Render). Set env vars: MONGODB_URI, JWT_SECRET,
   FRONTEND_URL=https://werthausverwaltung.de (no slash), NODE_ENV=production.
3. Frontend Vercel project → set REACT_APP_API_URL=https://YOUR-BACKEND/api → REDEPLOY.
4. Point werthausverwaltung.de at the frontend project.

## Generate a JWT_SECRET
    node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
